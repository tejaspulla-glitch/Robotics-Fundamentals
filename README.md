# Robotics-Fundamentals

Python simulations of simple mechanical systems. This is the first stage of my robotics learning path: linear algebra, basic physics, and numerical simulation.

## Projects

- **Rotations:** rotating a 2D shape with a rotation matrix
- **Falling ball:** a ball falling with air drag
- **Spring-mass-damper:** a spring with three damping cases
- **Pendulum:** a swinging pendulum, compared to the small-angle approximation

## Requirements

Python 3 with NumPy, SciPy, and Matplotlib:

```
pip install numpy scipy matplotlib
```

## Running

Run any script from the repo folder, for example:

```
python spring.py
```
